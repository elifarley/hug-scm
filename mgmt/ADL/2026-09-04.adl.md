## 09:56 — hug-scm#286 BATS helper contract: pipe-shape assert_bytes_eq; _init_repo_at with pass-through --initial-branch

**Context**: Implementing elifarley/hug-scm#286 (DRY the BATS test helpers). Inventory on origin/main 292bbb36 found 9 od-oracle assertion sites across 3 files (tests/lib/test_hug_git_diff.bats x3, tests/lib/test_hug_git_show.bats x1, tests/unit/test_sh.bats x5) each re-carrying the NUL/od tribal-knowledge comment, and 11 t@t.tld identity-stanza sites in 2 files with 4 shapes: bare git init -q in CWD (x3), --initial-branch=master (x4), --initial-branch=main (x1), init-at-path (x2), plus 1 config-only site on an existing submodule repo (no init).
**Decision**: assert_bytes_eq uses the PIPE call shape: producer | assert_bytes_eq '<od-canonical-expected>' — it reads stdin and wraps od -An -c | tr -d ' \n', so each converted site keeps its producer untouched and its expected string byte-identical (pure mechanical diff). For fixtures, _init_repo_at <path> [--initial-branch=<name>] matches the UNION of real usage: positional path plus explicit pass-through --initial-branch flag (>=2 variants exist, so a flag beats baking in one branch name), delegating the identity literals to a shared _git_test_identity [dir] building block so the config-only submodule site (test_hug_git_diff.bats:202-205) collapses onto the same literals without re-initializing an existing repo. Deliberately minimal: NO hermetic extras from create_test_repo (hooksPath/excludesFile/aliases/initial commit) — adding those would change fixture semantics, violating the zero-drift requirement.
**Alternatives**: Passing the producer command as arguments to assert_bytes_eq (rejected: re-quoting command strings is where drift sneaks in; pipe shape keeps the diff one-to-one). Process-sub redirection (rejected: unfamiliar shape). Dominant-variant _init_repo_at without the flag (rejected: 5 of 8 init sites need --initial-branch; baking 'master' would force outliers into explicit re-config). Leaving the config-only submodule site unconverted (rejected: identity literals stay duplicated, the exact drift risk the issue targets).
